# InvoiceGuard Forms build sheet
Generated by `forms/tools/gen_forms_xml.py` from the same model that writes the
XML. Use this sheet if `frmxml2f` is unavailable: build each module in Forms Builder by
hand, then paste the code from `forms/plsql/<MODULE>_triggers.pls` and
`forms/plsql/<MODULE>_program_units.pls`.
## Conventions
* Coordinate system: Real, unit Point (Forms default 'Real' is assumed; confirm in Module Properties).
* Every button: `WHEN-BUTTON-PRESSED` = `BEGIN ... EXCEPTION WHEN OTHERS THEN ig_msg.show_error(SQLERRM); END;`
  `ON-ERROR` = `ig_msg.show_error;` (no argument).
  then a refresh. Navigation and Audit Trail buttons call `ig_nav` only (no SPEC package API).
* Forms never write `status`, `risk_score`, `approved_by` or hold rows. Invoice status is display only.
* Shared PL/SQL library `IG_LIB` (see `forms/IG_LIB.pld`) is attached to every form.
* Alerts `IG_ERROR_ALERT` and `IG_CONFIRM_ALERT` and visual attributes `VA_HIGH`, `VA_MEDIUM`,
  `VA_LOW` are defined in every form (VA_LOW is the default look).
